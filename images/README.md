# 이미지 넣는 법

이 폴더에 아래 파일명으로 저장하면 페이지에 자동으로 표시됩니다. 파일이 없으면 그 자리에 규격이 적힌 빈 칸이 보입니다.
PNG 또는 JPG, 가로세로 비율은 맞추고 크기는 2배(레티나)로 만들면 선명합니다.

| 파일명 | 위치 | 크기 (px) | 내용 제안 |
|---|---|---|---|
| `hero.png` | 첫 화면 오른쪽 | 1040 × 1120 | 앱 화면 1~2개 (지급 내역 / 신고 완료) |
| `step-1.png` | 이용 방법 1단계 | 420 × 660 | 홈 화면 (위쪽 둥근 모서리, 아래는 잘려도 됨) |
| `step-2.png` | 이용 방법 2단계 | 420 × 660 | 지급 내역 입력 화면 |
| `step-3.png` | 이용 방법 3단계 | 420 × 660 | 세금 확인·신고 화면 |
| `feature-calc.png` | 기능 1 · 세금 자동 계산 | 760 × 920 | 세액 계산 결과 화면 |
| `feature-hometax.png` | 기능 2 · 홈택스 신고 | 760 × 920 | 신고 내역 화면 |
| `feature-alert.png` | 기능 3 · 마감 알림 | 760 × 920 | 카카오톡 알림 화면 |
| `who-1.png` | 추천 대상 1 아이콘 | 64 × 64 | 스튜디오·에이전시 |
| `who-2.png` | 추천 대상 2 아이콘 | 64 × 64 | 학원·공부방 |
| `who-3.png` | 추천 대상 3 아이콘 | 64 × 64 | 학원·교습소 |
| `who-4.png` | 추천 대상 4 아이콘 | 64 × 64 | 출판사·콘텐츠 제작사 |

큰 이미지는 `object-fit: cover`로 칸에 꽉 차게 들어가고 모서리가 둥글게 잘립니다. 가장자리에 중요한 내용을 두지 마세요.
