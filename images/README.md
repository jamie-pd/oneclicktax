# 이미지 넣는 법

폰 목업 6개(히어로, 이용 방법 1~3, 기능 2개)는 이미지 파일이 아니라 `index.html` 안의 HTML이에요. 고치는 방법은 아래 "현재 이미지 수정하기"를 보세요.

추천 대상 아이콘은 이 폴더에 아래 파일명으로 저장하면 페이지에 표시됩니다. 파일이 없으면 그 자리에 빗금 칸이 보입니다.

| 파일명 | 위치 | 크기 (px) | 내용 |
|---|---|---|---|
| `who-1.png` | 추천 대상 1 아이콘 | 64 × 64 | 스튜디오·에이전시 |
| `who-2.png` | 추천 대상 2 아이콘 | 64 × 64 | 학원·공부방 |
| `who-3.png` | 추천 대상 3 아이콘 | 64 × 64 | 학원·교습소 |
| `who-4.png` | 추천 대상 4 아이콘 | 64 × 64 | 출판사·콘텐츠 제작사 |

## 현재 이미지 수정하기

- **폰 목업 6개(히어로, 이용 방법 1~3, 기능 2개)는 이미지가 아니라 `index.html` 안의 HTML입니다.** 원본은 `_source/frames.html`이고, 원클릭 원천세 Figma 'ㄴ가입,신고 플로우' 페이지의 실제 화면을 위치·색·글자 값 그대로 옮긴 것입니다. 목업 안에서 쓰는 아이콘은 `images/app/`(Figma 원본), 3D 그래픽은 `images/3d/`에 있습니다.
- 문구나 금액을 바꾸려면 `_source/frames.html`을 고친 뒤 아래 명령으로 `index.html`에 다시 넣으세요 (Node + Playwright 필요). 같은 자리만 교체됩니다. `index.html` 안의 `mk-` 코드는 직접 고치지 마세요.

```bash
node images/_source/embed.js
```

- SNS나 Figma에 쓸 PNG가 필요하면 `node images/_source/render.js`를 실행하세요. `images/_source/png/`에 2배 크기로 저장됩니다.
- 추천 대상 아이콘(`who-*.png`)은 Figma AI로 만든 글래스 3D 그래픽(`_source/3d/`)을 64px로 줄인 PNG입니다.
