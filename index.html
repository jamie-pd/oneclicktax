이용 방법

원천세 신고, 이렇게 간단해져요

세무 지식이 없어도 괜찮아요. 화면을 따라 세 단계만 거치면 신고가 끝나요.

1

카카오로 로그인

번거로운 회원가입 없이 카카오 계정 하나로 시작할 수 있어요.

2

지급 내역 입력

누구에게 얼마를 지급했는지 입력해요. 지난달 내역을 불러오면 금액만 고치면 돼요.

3

세금 확인 후 신고

이번 달 낼 세금을 바로 보여드려요. 확인 후 신고 버튼을 누르면 홈택스에 접수돼요.

세금 자동 계산

3.3%? 8.8%?
세율은 몰라도 괜찮아요

급여인지, 외주비인지, 강연료인지만 선택하세요. 소득 종류에 맞는 세율이 자동으로 적용되고, 소득세와 지방소득세가 바로 계산돼요.

  • 급여, 외주비, 강연료, 일당 모두 지원
  • 복잡한 절사·소액부징수 규칙도 자동 반영
  • 받는 사람에게 실제 입금할 금액까지 표시

홈택스 신고

홈택스 화면,
이제 안 봐도 돼요

입력한 내역으로 신고서를 자동 작성해 홈택스에 제출해요. 놓치기 쉬운 지급명세서도 함께 제출되니 가산세 걱정 없이 매달 신고를 마칠 수 있어요.

  • 원천징수이행상황신고서 자동 작성·제출
  • 간이지급명세서까지 함께 제출돼요
  • 신고 후 납부 금액과 계좌 안내

마감 알림

매달 10일,
잊어버릴 틈이 없어요

한 달에 한 번이라 더 잊기 쉬운 원천세. 마감 전에 카카오톡으로 알려드리고, 알림에서 바로 신고 화면으로 이어져요.

  • 마감 3일 전과 당일, 두 번 알림
  • 반기납부 사업장은 1월·7월 일정에 맞춰 알림
  • 신고 완료와 납부 기한도 알림으로 안내

자주 묻는 질문

저도 원천세 신고 대상인가요?
직원에게 급여를 주거나 프리랜서에게 외주비를 지급했다면 대상이에요. 지급할 때 미리 떼어 둔 세금을 다음 달 10일까지 신고·납부해야 해요.
세무사 없이 직접 신고해도 되나요?
네. 지급 내역만 입력하면 세액 계산과 신고서 작성이 자동으로 이루어져요. 금액을 확인하고 신고 버튼을 누르면 됩니다.
3.3%와 8.8%는 무엇이 다른가요?
계속 거래하는 프리랜서에게 주는 외주비는 사업소득으로 3.3%, 강연료·원고료처럼 일시적으로 지급하는 돈은 기타소득으로 8.8%를 원천징수해요. 지급 종류를 선택하면 자동으로 구분됩니다.
홈택스 아이디나 공동인증서가 필요한가요?
가입은 카카오 계정만으로 가능해요. 홈택스 신고를 연결할 때 사업자 정보를 한 번 확인하면 이후에는 매달 별도 로그인이 필요 없어요.
세금 납부도 대신 해주나요?
납부 금액과 가상계좌를 안내해 드려요. 납부는 사업자 계좌에서 직접 이체해야 해요.
반기납부 사업장도 이용할 수 있나요?
네. 반기납부로 설정하면 6개월치 내역을 모아 7월과 1월에 신고해요. 매달 제출해야 하는 지급명세서는 별도로 처리돼요.
